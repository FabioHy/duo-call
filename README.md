# Duo 💖

> Aplicativo desktop privado de chamada de voz, vídeo, transmissão de tela e chat 1-a-1 feito sob medida para casais.

![Duo Interface](public/assets/couple-art.jpg)

## ✨ Funcionalidades

- 🎙️ **Chamada de Voz com Detecção de Fala (VAD):** Indicador com auréola verde neon ao redor do avatar quando o usuário fala.
- 🖥️ **Transmissão de Tela & Janelas de Aplicativos:** Compartilhe a tela cheia ou selecione janelas específicas (jogos, navegador, etc.) com áudio do sistema e modo Tela Cheia nativo.
- 💬 **Chat em Tempo Real:** Conversa direta com timestamps, avatares e envio de reações flutuantes de coração.
- 👤 **Perfis Personalizáveis:** Altere nome e faça upload de foto de perfil salva localmente e sincronizada em tempo real.
- 📝 **Bloco de Notas Sincronizado:** Área compartilhada para listar filmes, jogos e recados a dois.
- 🎨 **Tema Midnight Navy:** Design moderno e intimista estilo Discord.

## 🚀 Como Executar Localmente

```bash
# 1. Instalar dependências
npm install

# 2. Iniciar o app desktop
npm start
```
